# Подключения: заявки, Telegram, Метрика

Всё делается один раз и без программиста. После каждого шага сайт начинает работать чуть
полнее — можно останавливаться в любой момент.

Править нужно только один файл: **`site/assets/js/config.js`**.

---

## Часть 1. Заявки в таблицу и в Telegram

Зачем посредник: отправлять заявку напрямую в Telegram из кода сайта нельзя — токен бота
был бы виден любому посетителю. Google Apps Script живёт в твоём Google-аккаунте,
токен лежит там.

### Шаг 1. Таблица

1. Создай пустую Google-таблицу, назови «fibby — заявки».
2. Скопируй её **ID** из адреса. В ссылке
   `https://docs.google.com/spreadsheets/d/`**`1AbCdEf...XyZ`**`/edit`
   ID — это выделенная часть.

### Шаг 2. Скрипт

1. Открой [script.google.com](https://script.google.com) → «Новый проект».
2. Назови проект «fibby leads».
3. Удали всё из редактора и вставь содержимое файла `site/integrations/apps-script.gs`.

### Шаг 3. Секреты

В редакторе: шестерёнка «Настройки проекта» → «Свойства скрипта» → «Добавить свойство».
Добавь:

| Свойство | Значение |
|---|---|
| `SHEET_ID` | ID таблицы из шага 1 |
| `TG_TOKEN` | токен бота из части 2 (можно добавить позже) |
| `TG_CHAT_ID` | твой ID из части 2 (можно добавить позже) |

Без `TG_TOKEN` заявки просто пишутся в таблицу — тоже рабочий вариант.

### Шаг 4. Публикация

1. «Начать развёртывание» → «Новое развёртывание» → тип **«Веб-приложение»**.
2. «Запуск от имени» — **от моего имени**.
3. «У кого есть доступ» — **у всех**.
   Это обязательно: сайт обращается к скрипту от имени посетителя, не зная его аккаунта.
   Скрипт умеет только принять заявку, читать твою таблицу через него нельзя.
4. Нажми «Развернуть», разреши доступ (Google предупредит, что приложение не проверено —
   это твой собственный скрипт, нажми «Дополнительно» → «Перейти»).
5. Скопируй **URL веб-приложения** — длинная ссылка, заканчивается на `/exec`.

### Шаг 5. Вписать ссылку в сайт

В файле `site/assets/js/config.js`:

```js
window.FB_LEAD_ENDPOINT = 'https://script.google.com/macros/s/AKfy.../exec';
```

Готово: заявки с сайта падают в таблицу. Проверить можно сразу — оставь предзаказ
на сайте и посмотри в таблицу.

### Если что-то меняешь в скрипте позже

Apps Script не обновляет опубликованную версию сам: после правок нужно
«Начать развёртывание» → «Управление развёртываниями» → карандаш → «Версия: Новая» → «Развернуть».
Ссылка при этом не меняется.

## Часть 2. Telegram-бот

1. В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — любое, ник должен заканчиваться на `bot`, например `fibby_leads_bot`.
3. BotFather пришлёт **токен** вида `7123456789:AAE...`. Это пароль бота, не публикуй его.
4. Напиши своему боту любое сообщение — иначе он не сможет написать тебе первым.
5. Узнай свой **chat_id**: напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число.
6. Впиши токен и число в свойства скрипта (шаг 3) как `TG_TOKEN` и `TG_CHAT_ID`.
7. В редакторе скрипта выбери функцию `testLead` и нажми «Выполнить» — должна прийти
   тестовая заявка в Telegram и строка в таблицу.

Если заявки нужны не тебе лично, а в общий чат с Федей — добавь бота в чат, сделай его
администратором и используй chat_id чата (у групп он с минусом, например `-1001234567890`).

## Часть 3. Яндекс Метрика

1. Зайди на [metrika.yandex.ru](https://metrika.yandex.ru) → «Добавить счётчик».
2. Имя — fibby, адрес сайта — твой домен (можно поменять позже), включи **Вебвизор**.
3. Скопируй **номер счётчика** — 8 цифр.
4. В `site/assets/js/config.js`:

```js
window.FB_METRIKA_ID = 98765432;
```

Счётчик подключится сам, код вставлять не нужно.

### Цели

Сайт уже отправляет четыре цели. В Метрике их нужно один раз создать:
«Настройки» → «Цели» → «Добавить цель» → тип **«JavaScript-событие»**, идентификатор — из таблицы.

| Идентификатор | Что считает |
|---|---|
| `preorder_click` | клик по любой кнопке предзаказа |
| `lead_submit` | отправленная заявка — **главная метрика** |
| `flavor_change` | смена вкуса |
| `plan_select` | выбор набора |

Пока счётчик не подключён, цели видно в консоли браузера — работу проверить можно и без него.

### Как считать блогеров

Каждому блогеру — своя ссылка с его промокодом:

```
https://fibby.ru/?promo=SUREN10&utm_source=instagram&utm_medium=blogger&utm_campaign=sentyabr
```

Промокод попадает в заявку и в таблицу, поэтому процент блогеру считается по таблице,
а переходы и конверсию видно в Метрике по UTM. Метка живёт в браузере 30 дней: если
человек пришёл по ссылке блогера сегодня, а оставил заявку через неделю — заказ
всё равно зачтётся ему.

## Часть 4. Юридические данные

В `site/assets/js/config.js`:

```js
window.FB_LEGAL = {
  entity: 'ИП Фамилия Имя Отчество',
  inn: '770123456789',
  email: 'hi@fibby.ru'
};
```

Подставится в подвал и в политику обработки персональных данных.
Пока не заполнено — на сайте стоят плейсхолдеры `[__]`.

**Важно:** текст политики в `site/privacy.html` — черновик по 152-ФЗ. До сбора реальных
заявок его должен посмотреть юрист. Собирать контакты без политики и без галочки
согласия нельзя.
