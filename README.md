# fibby — папка проекта

Всё, что надумали в чате с Claude, в одном месте: бриф, решения, бренд, ТЗ сайта, упаковка, референсы и исходники концептов.

## Как продолжить в терминале

1. Распакуй папку, например в `~/Projects/fibby`.
2. В терминале:
   ```bash
   cd ~/Projects/fibby
   git init && git add . && git commit -m "fibby: стартовый пакет"
   claude
   ```
3. Claude Code сам прочитает `CLAUDE.md` — там контекст и правила.
4. Первым сообщением вставь текст из `START_PROMPT.md`.

Чтобы работать вдвоём, залей папку в приватный репозиторий на GitHub и клонируйте оба.

## Что где

| Папка / файл | Что внутри |
|---|---|
| `CLAUDE.md` | Контекст и правила для Claude Code |
| `START_PROMPT.md` | Первый промпт для терминала |
| `docs/01-brief.md` | Продукт, модель, спрос, каналы, закон, риски |
| `docs/02-decisions-log.md` | Что и когда решили |
| `brand/` | Бренд-гайд и токены (JSON + CSS-переменные) |
| `site/SPEC.md` | ТЗ лендинга по секциям + анимации и 3D |
| `packaging/SPEC.md` | Упаковка: направления, обязательная маркировка, вопросы фабрике |
| `references/references.md` | Разбор Trenchies, More, Olipop, Graza и других |
| `concepts/` | Исходники артбордов v1–v3 (формат холста Claude, только для референса) |
