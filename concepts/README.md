# Концепты

Исходники артбордов с холста Claude Design. Формат `.dc.html`: шаблон с `{{...}}`, `<sc-for>`, `<sc-if>` и классом `DCLogic`. В браузере напрямую **не откроется** — это референс разметки, текстов, цветов и логики. Живьём всё смотрится на холсте (ссылка в README в корне).

- `v3/` — рабочая версия: Brand3 (бренд-борд), Pack3 (упаковка: основная, с окном, оборот, мини), Landing3 (лендинг с переключателем вкуса)
- `v2/` — clean-версия: бренд-борд, линейка из трёх пачек, лендинг
- `v1/` — отклонённый «конфетный» вариант, оставлен для истории
